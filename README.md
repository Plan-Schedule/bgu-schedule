# מתכנן מערכת שעות · בן-גוריון

**https://plan-schedule.github.io/bgu-schedule/**

אפליקציית ווב קטנה שעוזרת לבנות מערכת שעות לסמסטר באוניברסיטת בן-גוריון.
עובדת בטלפון ובמחשב, בלי הרשמה ובלי שרת. אפשר להשתמש בה ישירות מהקישור, או
להתקין אותה למסך הבית (PWA), ואז היא עובדת גם בלי אינטרנט.

> כלי עצמאי של סטודנטים, לא אתר רשמי של האוניברסיטה. ראו [אודות, פרטיות ותנאי שימוש](about.html).

## מה אפשר לעשות

- **לחפש קורסים** לפי שם או מספר (למשל `לוגיקה` או `212.1.0201`) ולהוסיף אותם.
- **לדרג מרצים ומתרגלים**: ⭐ מומלץ / 🚫 להימנע. הדירוג הוא לפי אדם, כך שאם אותו מרצה מלמד בכמה קורסים או בכמה קבוצות, מדרגים אותו פעם אחת.
- **להחליט לכל קורס** אם הולכים להרצאות ולתרגולים, רואים הקלטות או לא הולכים, ועד כמה חשוב מי מלמד.
- **לנעול קבוצות**: 📌 חובה, ⛔ לא מתאים.
- **לסמן אילוצים** על לוח שבועי: "לא יכול" או "עדיף שלא". האילוצים חלים רק על שיעורים שהולכים אליהם.
- **לקבל את המערכות הכי טובות**. כל אחת מהן היא מערכת שאפשר באמת להירשם אליה: אין התנגשויות, וכל תרגול שייך להרצאה שלו. לכל מערכת מוצג מה קיבלת ועל מה ויתרת, ואפשר להשוות בין שתיים.
- **לתכנן לאן הולכים בפועל**: על כל שיעור במערכת ששמרת מסמנים אלך / הקלטה / לא אלך / אלך לקבוצה אחרת. אפשר גם להחליף קבוצה ברישום.
- **לייצא**: רשימה להקלדה במערכת הרישום, קישור לשיתוף עם חברים, תמונה ליומן, וקובץ יומן (ics).

### שלושה סוגי קישורים

| קישור | מה יש בו | למי |
|---|---|---|
| `#s=…` מערכת | מספרי קבוצות ושם המערכת | חברים |
| `#c=…` רשימת קורסים | מספרי קורסים ושם הרשימה | קבוצת המחזור |
| `#r=…` קישור שחזור | כל הנתונים, כולל הדירוגים | רק לעצמך (מעבר מכשיר / גיבוי) |

כל קישור שנפתח נחשב קלט ממקור לא מוכר ועובר סינון (`sanitizePlan`, `decodeCourseList`,
`sanitizeState` ב-`js/share.js`) לפני שמשהו ממנו מוצג.

הבחירות נשמרות בדפדפן בלבד. כדי לעבור בין מכשירים שולחים לעצמך קישור שחזור (⚙︎ ← "שליחת קישור שחזור לעצמי")
או משתמשים בקובץ גיבוי.

## איך זה עובד

| תיקייה | מה יש בה |
|---|---|
| `index.html`, `css/`, `js/` | האפליקציה (HTML/JS רגיל, בלי שלב בנייה) |
| `js/model.js` | הלוגיקה: אפשרויות רישום, חיפוש מערכות, ניקוד |
| `js/config.js` | כל מה שייחודי לאוניברסיטה ולפריסה (שם, קישורים, כתובת לטופס ההערות) |
| `sw.js`, `manifest.webmanifest` | התקנה ועבודה בלי אינטרנט |
| `about.html` | אודות, פרטיות, תנאי שימוש ונגישות |
| `data/` | קובץ הקורסים, כקבצי JSON |
| `scraper/` | הסקריפט שמוריד את קובץ הקורסים מ-bgu4u |
| `.github/workflows/update-catalog.yml` | מריץ את הסקריפט כל יום ושומר שינויים |

השנים והסמסטרים מוגדרים ב-`scraper/semesters.txt`. השורה `auto` מחשבת לבד את שנת הלימודים הנוכחית ואת הסתו הבא,
כך שבשנה חדשה לא צריך לשנות כלום. סמסטר שהאוניברסיטה עוד לא פרסמה פשוט מדולג עד שיתפרסם.

### טופס ההערות

כפתור "יש לי הערה" מוביל ל-`feedbackUrl` שב-`js/config.js`. כברירת מחדל זה טופס Issue ב-GitHub,
שדורש חשבון GitHub. כדי שכל סטודנט יוכל לשלוח הערה, פותחים טופס Google חינמי ומדביקים את הקישור שלו שם.

### הרצה מקומית

```sh
python3 -m http.server 8000        # ופותחים http://localhost:8000
node --test scraper/test/*.test.mjs test/*.test.mjs
node scraper/scrape.mjs --year 2027 --sem 1                    # כל הקורסים (~20 דקות)
node scraper/scrape.mjs --year 2027 --sem 1 --only 212-1-0201  # קורס אחד
```

### פרסום (GitHub Pages)

Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main**, תיקייה **/ (root)**.

כשמשנים קבצים של האפליקציה, מעלים את `VERSION` ב-`sw.js` כדי שמכשירים שהתקינו אותה יקבלו את הגרסה החדשה מיד.

> המידע נלקח מקובץ הקורסים הציבורי של האוניברסיטה ועלול להשתנות. לפני הרישום כדאי לוודא את השעות באתר האוניברסיטה.
